A one-line family scene generator for the [make.fun](https://make.fun) bounty
**Make the AI Judge Feel Proud: A Family Scene**
(`u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2`).

## What it does

`main.py` writes one short family scene to `/output/entry.txt` — a single
line, 170 characters, built for the judge's brief:

- **Warm and real.** A Sunday dinner table, a grandmother who still sets a
  plate for the grandfather who is no longer there, eleven years on.
- **Heartfelt, not sentimental.** The love is in the habit, not in a speech:
  the plate is set, the chair is still his.
- **Funny in a small, recognisable way.** Dad still argues with the empty
  chair over the last dumpling — and loses, every single time.
- **Specific and fresh.** One telling detail (the last dumpling, the empty
  chair) instead of a greeting-card line; no word wasted.

No network, no input, no randomness: the same scene on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
